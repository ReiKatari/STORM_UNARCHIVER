<h1 align="center">STORM UNARCHIVER</h1>

## **О проекте**
STORM UNARCHIVER — высокопроизводительный многопоточный архиватор и распаковщик архивов для Windows. Поддерживает все популярные и специализированные форматы архивов (ZIP, 7Z, RAR, TAR, GZ, BZ2, XZ, ZST, ISO, CAB, LHA, ARJ) с возможностью автоматического подбора паролей из словарей, восстановления поврежденных данных и интеграцией в контекстное меню Проводника.

## **Происхождение и форки**
Оригинальная разработка на базе открытого движка архиватора **7-Zip** (Игорь Павлов) и библиотек SharpCompress.

## **Технологический стек**
- **Языки программирования**: C# (.NET 9.0), C++
- **Интерфейс**: WPF, XAML, Интеграция с Windows Shell Context Menu
- **Движки распаковки**: 7-Zip Standalone Core (7z.dll), SharpCompress, Zstandard native lib

## **Ключевые возможности**
- **Поддержка всех форматов**: Мгновенная распаковка и создание архивов 7z, ZIP, TAR, GZ, XZ, Zstd, RAR5.
- **Многопоточная декомпрессия**: Максимальная скорость работы за счет распараллеливания блоков данных на все ядра CPU.
- **Умный подбор паролей**: Автоматическая проверка паролей из пользовательского словаря при распаковке защищенных архивов.
- **Интеграция в контекстное меню Windows**: Удобные пункты «Распаковать здесь», «Распаковать в папку» в Проводнике.

## **Поддерживаемые платформы и эмуляторы**
- **Операционные системы**: Windows 10, Windows 11 (x64)

## **Установка и запуск**
1. Скачайте инсталлятор `STORM_UNARCHIVER_<версия>_Setup.exe` или архив `STORM_UNARCHIVER_<версия>.zip` из раздела **Releases**.
2. Установите приложение для интеграции с системным проводником.
