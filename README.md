<h1 align="center">STORM UNARCHIVER</h1>

## **О проекте**
STORM UNARCHIVER — высокопроизводительный инструмент для автоматического фонового мониторинга и пакетной распаковки архивов в реальном времени под Windows. Поддерживает более 100 форматов архивов и образов дисков (ZIP, RAR, 7Z, TAR, GZ, ISO, APK, CAB, BZ2, XZ, ZST, DMG, VHD и другие) с интеллектуальным перебором паролей по словарям, рекурсивной распаковкой вложенных архивов, гибкой фильтрацией и энергоэффективным эко-режимом.

## **Происхождение и форки**
Разработка экосистемы STORM SOFT на базе открытого движка архиватора **7-Zip** (Игорь Павлов) и библиотеки **SharpCompress** (Adam Hathcock).

## **Технологический стек**
- **Платформа и фреймворк**: C# (.NET 8.0), Windows App SDK (WinUI 3)
- **Графическая подсистема**: XAML, Mica Backdrop, аппаратно-ускоренные анимации
- **Движки распаковки**: 7-Zip Standalone Core, SharpCompress
- **Интеграция с системой**: Фоновый системный трей (Message Window P/Invoke), Shell File Picker, FileSystemWatcher

## **Ключевые возможности**
- **Автоматический мониторинг папок**: Мгновенное обнаружение и фоновая декомпрессия новых архивов в неограниченном количестве пар каталогов.
- **Поддержка 100+ форматов**: ZIP, RAR, 7Z, TAR, GZ, ISO, APK, CAB, BZ2, XZ, ZST, DMG, VHD, MSIX, CPIO, DEB, RPM, WIM и многие другие.
- **Интеллектуальный словарь паролей**: Автоматический подбор паролей по пользовательским словарям и текстовым базам данных.
- **Рекурсивная распаковка**: Автоматическое извлечение вложенных архивов до заданной глубины вложенности.
- **Эко-режим и регулировка нагрузки**: Фоновый режим работы с пониженным приоритетом CPU и дисковой подсистемы.
- **8 стандартизированных тем оформления**: STORM DARK, STORM NIGHT, STORM DAY, STORM MIDNIGHT, STORM MATRIX, STORM CYBERPUNK, STORM FANTASY, STORM WARHAMMER 40K.
- **100% локализация интерфейса**: Поддержка 6 языков (Русский, English, Deutsch, Français, 简体中文, 日本語) с переключением на лету.
- **Single Instance Mode**: Контроль единственного экземпляра приложения с автоматической активацией активного окна.

## **Поддерживаемые платформы**
- **Операционные системы**: Windows 10, Windows 11 (x64)

## **Установка и запуск**
1. Скачайте инсталлятор `STORM_UNARCHIVER_1.0.0_Setup.exe` из раздела **Releases**.
2. Запустите установщик и следуйте указаниям мастера.
3. Программа готова к фоновой работе и автоматическому мониторингу.
